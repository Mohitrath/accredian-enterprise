# Accredian Enterprise — Partial Clone

A student partial clone of the Accredian Enterprise landing page built for a Full Stack Developer Intern assignment.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Next.js Route Handler for the lead form

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm run start
```
